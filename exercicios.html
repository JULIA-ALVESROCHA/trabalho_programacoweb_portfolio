Respostas dos exercícios de observação

Lista 1, Ex. 4: inspecionando um elemento

Abri a página inicial, cliquei com o botão direito no meu nome e escolhi Inspecionar (ou F12). O DevTools mostrou o elemento <h1>Júlia Rocha</h1> e o CSS aplicado a ele.

Comparei com o <title> dentro do <head>. O <h1> aparece dentro da página. O <title> aparece na aba do navegador, nos favoritos e nos resultados de busca.

Lista 1, Ex. 5: codificação de caracteres

Todas as páginas usam <meta charset="utf-8">, então os acentos do português aparecem certos.

No arquivo de teste, troquei para windows-1252. O arquivo continua salvo em UTF-8, então o navegador lê os bytes de outro jeito. "Ciência" vira algo como "CiÃªncia". Voltando para UTF-8, o texto fica normal de novo.

Lista 1, Ex. 6: a descrição nos buscadores

Cada página tem uma <meta name="description"> própria. Buscadores como o Google podem mostrar esse texto embaixo do título no resultado da pesquisa. Por isso a descrição deve ser curta, ter as palavras importantes e explicar o que a pessoa vai encontrar.

Para testar, pesquise "MDN Web Docs" no Google. O texto embaixo do link costuma ser o mesmo da meta description do site da MDN.
