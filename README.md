# Portfólio Júlia Rocha

Site pessoal feito em HTML, CSS e JavaScript puros. Não usa framework nem etapa de build.

Ele também reúne a entrega de três listas de exercícios da disciplina:

1. Introdução à HTML (exercícios da MDN)
2. Marcação fundamental HTML para elementos de texto (exercícios da MDN)
3. Instalando o plugin WooCommerce e criando o primeiro produto

## Como abrir o site

**No computador:** baixe ou clone o repositório e abra o `index.html` no navegador.

## Onde está cada exercício

Cada exercício está marcado no código com um comentário, por exemplo `<!-- Lista 2, Ex. 4 -->`.
A página `exercicios.html` mostra o mesmo mapa com links.

### Lista 1: Introdução à HTML

| Nº | Exercício | Onde está |
| --- | --- | --- |
| 1 | Creating your first HTML element | `index.html`: parágrafo com `<em>` |
| 2 | Adding attributes to an element | `index.html` e `contato.html`: `href`, `title`, `target`, `rel` |
| 3 | Adding some features to an HTML document | `index.html`: `<h1>`, `<strong>`, link e imagem com `alt` |
| 4 | Inspecting a single element | Resposta em `exercicios.html` |
| 5 | Experiment with character encoding | `<meta charset="utf-8">` em todas as páginas e `extras/teste-encoding.html` |
| 6 | The description's use in search engines | `<meta name="description">` em todas as páginas |
| 7 | Applying CSS and JavaScript to a page | `css/estilo.css` e `js/script.js` |

### Lista 2: Elementos de texto

| Nº | Exercício | Onde está |
| --- | --- | --- |
| 1 | Giving our content structure | `index.html` e `experiencia.html` |
| 2 | Marking up an unordered list | `index.html`, `experiencia.html`, `elos-code.html` |
| 3 | Marking up an ordered list | `elos-code.html` (modo de preparo) |
| 4 | Marking up our recipe page | `elos-code.html` (A receita do Elos Code) |
| 5 | Let's be important! | `index.html` e `elos-code.html` |
| 6 | Test your skills: HTML text basics | `projetos.html`, `elos-code.html`, `extras/glossario.html` |
| 7 | Creating your own example link | `index.html` (link para a MDN) |
| 8 | Creating a navigation menu | `<nav>` no topo de todas as páginas |
| 9 | Test your skills: Links | `contato.html`, `projetos.html`, `extras/glossario.html`, `index.html` |
| 10 | Marking up a set of definitions | `extras/glossario.html` e `elos-code.html` |
