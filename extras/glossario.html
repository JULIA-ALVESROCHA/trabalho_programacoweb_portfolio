Glossário

Os termos que aparecem no portfólio, explicados em poucas palavras.

Inteligência Artificial (IA)
Área da Computação que cria sistemas capazes de realizar tarefas que normalmente exigem inteligência humana, como entender texto ou reconhecer imagens.
LLM
Sigla de Large Language Model. É um modelo de linguagem treinado com muito texto, capaz de gerar e interpretar frases.
Alucinação
Quando um modelo de IA dá uma resposta que parece certa, mas é inventada ou falsa.
RAG
Geração Aumentada por Recuperação. O sistema primeiro busca trechos em fontes confiáveis e só depois gera a resposta com base neles. É a técnica usada no chatbot BGO.
BERT
Modelo de linguagem criado pelo Google, muito usado para classificar textos e encontrar informações.
Extensão universitária
Projeto em que a universidade leva conhecimento para a comunidade fora dela. O Elos Code é um projeto de extensão.
ENEM
Exame Nacional do Ensino Médio, a principal porta de entrada para as universidades públicas do Brasil.
